# Share Wyn (after a real download exists)

Do not post “Introducing Wyn 1.0” until there is a notarized DMG. Until then,
point people at a **verified game page** and the source install.

Wyn is free. Do not pitch paid tiers until there are installs.

## Landing URLs

- Catalog: https://wyn-dev.com/
- Source: https://github.com/JellyBean47/wyn
- A title: https://wyn-dev.com/games/solarpunk
- JSON: https://wyn-dev.com/api/v1/games/solarpunk.json

## Titles that search better than a launch announcement

- I got Solarpunk running on an M4 Mac
- Satisfactory on Mac with Wyn (D3DMetal, MetalFX off)
- DXMT vs D3DMetal on the same game
- Can an M4 Mac run this Windows Steam game?

End the post with: Wyn is open source. The profile is on wyn-dev.com. Guessed
is not verified.

Reddit (r/macgaming, r/apple, game-specific subs), YouTube, AppleGamingWiki.
Link the **verified** page, not a guessed one, unless you say it is a guess.
